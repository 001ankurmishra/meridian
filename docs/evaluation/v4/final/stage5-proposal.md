# Stage 5 entry proposal — approval required, not implemented

Scope: optional evidence-grounded explanation draft alongside the authoritative
deterministic report. No LLM numerical calculation, case decision, AML verdict,
account action, report filing, unrestricted SQL or independent tool execution.
Stage 4 research signals must not enter the prompt as validated risk conclusions.

Before implementation, review/update proposed ADR-0003 with one provider/model,
privacy/retention/region requirements, synthetic-only payload boundary, exact
structured schema, prompt/model versioning, timeout and cost cap. No provider is
selected here; a current official-document comparison is required once desired
budget/privacy constraints are supplied. No key, paid call or external data
transmission is authorized by this proposal.

Small initial implementation proposal: a thin optional provider adapter and
mock implementation; a separately labeled draft containing sentence-level source
IDs; deterministic ID/run ownership, numeric, schema and forbidden-action checks.
Existing IDs alone do not prove semantic support: include claim-to-passage review
and abstain on unsupported claims. Preserve original report and audit references.
API failure or invalid output must leave the deterministic workflow usable.

Acceptance before any live enablement: mocked CI tests for invented IDs/numbers,
cross-case injection, contradictory evidence, document prompt injection, malformed
output, timeout/failure and unsupported recommendations; independently reviewed
grounded examples; measured unsupported-claim rate, fidelity, abstention, latency
and cost. Human comparison remains NOT PERFORMED unless actually conducted.

Decision requested only when maintainer chooses to proceed: approve this bounded
Stage 5 scope, nominate privacy/cost constraints, and separately approve provider
selection and any paid usage. No Stage 5 code, LLM call or UI work is started.
